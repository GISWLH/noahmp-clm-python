# 三站官方首个气候年参考协议（2026-10-17）

本协议在官方输出产生前固定，使用未修改的HRLDAS `cd96df4` / Noah-MP
`17751dc`及[已迁移核验的二进制](HRLDAS_REFERENCE.md)。PBS36在EHPC计算节点
准备输入时遇到home inode上限，官方物理未启动；原输入已归档且只清理本次
生成的8636份临时强迫文件，恢复同数inode。PBS37保持同一准备/物理脚本，
改在计算节点/tmp准备和执行，再归档返回home，见[原失败与恢复](GPU_BLOCKERS.md)。
本机只编辑和静态检查。**这是冷启动结构性参考，不是已完成
三站10%验收**；后续逐日ET/H/土壤温湿和瞬时通量须实际对比并报告失败。

三站在各自站点内的文献假设T/Q/风高度相同，可直接映射官方单一ZLVL。
CN-Cng的T/Q为6 m、风为2 m，需要另行声明高度转换，因此本批未纳入；站点
选择与输出评分无关。原27组测高敏感性方案仍全部保留，不选最优高度。
Qia/Cha海拔采用站点研究者的[2007年ChinaFLUX介绍](https://asiaflux.net/?action=multidatabase_action_main_filedownload&download_flag=1&metadata_id=41&upload_id=53)；
较后的AsiaFlux一般站点页列100/731 m，差异保留。HaM采用已锁定JPF/ICOS产品
元数据，位置不混用旧FLUXNET海北产品；原海北填补降水可信度限制继续保留。

强迫来自当前四站气候年同一准备NPZ，读取前逐份核对SHA256。FLUXNET本地
标准时显式减UTC+8生成官方文件时间；降水从m/s转为mm/s，其余气象原值仅按
官方classic-NetCDF模式存成float32。每个物理区间的值写在其UTC右端文件，
符合官方强迫步长等于模型步长时的读取方式；起点文件只为初始化复制第一段。
所有写入值和单位按官方生成器schema逐文件回读核对，不插入或丢弃物理区间。
官方太阳位置从UTC时间计算，CLM既有站点运行器在区间中点计算；这项差异显式
保留。输出UTC时间将先严格核对，再由已声明的固定偏移映回相同本地日评分，
不能从局部日或太阳时移位中反选更好的相关性。

共同固定：1800秒步长、全年连续、零底部热通量、湿球降水相态5、VIC地表/
地下径流6、无城市/作物/灌溉/湿地/瓦片排水。温湿度初值、各站四层厚度和
零雪种子取当前CLM首个气候年的配置，未观测深层初态不伪称实测或spinup。
官方动态植被4使用标准MODIS月表物候，雪反照率1使用BATS，CO₂固定395 ppm，
短波直/散0.7/0.3；全部在输出前声明，不按结果调整表值。

与当前CLM的结构差异：CLM使用耦合C/N/GDD物候、分层Farquhar冠层、SNICAR、
站点CO₂/估计散射比例及明确的根分布。Qia/Cha的CLM名义壤土参数与官方STAS6
不相同；HaM同为STAS9。标准PFT叶参数、粗糙度及初始化冰水分配也可能不同。
因此不能把全部偏差自动归为代码错误，也不能据这些差别豁免最终科学验收。
首个冷启动周期与未来spinup、留出年和校准评价分别报告。

执行入口为[准备及官方运行脚本](../benchmarks/prepare_hrldas_climate_reference.py)。
每站准备清单保存所有强迫文件、setup、namelist和原NPZ/配置哈希；顶层协议
在官方主程序启动前写定，运行收据引用其哈希。私有运行库首尾核验不变，全部
失败保留。任何未完成或非有限输出都不能计为官方全年参考完成。
