# VIC 可变入渗与 ARNO 基流（开发中）

依据 [Noah-MP surface VIC 结构](https://raw.githubusercontent.com/NCAR/noahmp/master/src/RunoffSurfaceVicMod.F90)、
[VIC 参数说明](https://vic.readthedocs.io/en/master/Documentation/Definitions/)及
[VIC ARNO 出流结构](https://raw.githubusercontent.com/UW-Hydro/VIC/master/vic/vic_run/src/runoff.c)
独立实现公式，没有复制上游代码。这是单柱内的容量分布与底层蓄水出流，
不包含侧向地下水、汇流，也不是 Richards 方程。

`VICParameters` 显式给定 b、Ds、Dsmax、Ws、指数 c 和残余孔隙比例。
默认分别为 0.2、0.1、10 mm/day、0.9、2、0；它们是开发默认值，
并未作为任何站点的校准结果。要求 0≤Ds≤Ws<1，使 ARNO 曲线单调。

上面两个物理土层的厚度之和确定容量 C，液水和冰的总质量确定占用 W；
全部按 kg/m² 计算。令 D=C−W、x=(D/C)^(1/(1+b))，初始饱和面积为
1−x^b，剩余可入渗脉冲长度为 L=(1+b)Cx。来水 P<L 时，
I=D[1−(1−P/L)^(1+b)]，否则 I=D；地表出流 Q=P−I。
用 log1p/expm1 计算小脉冲，b=0 使用均匀容量极限 I=min(P,D)。
这里映射的是实际层厚和守恒蓄水，不把层底累计深度当成每层厚度重复累加。

只有 I 进入土壤状态，Q 携走同一份来水的比焓。降雨、冠层滴落/卸载后的
液水、雪融水均走此入口；直接在裸土凝结的霜露继续进入当地冰水存量。
雪层存在时先收纳来水，排液后才通过土壤入渗曲线。现有逐层孔隙容量
限制仍保留，意外溢出亦作为显式地表出流携热。

土层间继续使用既有 Campbell 重力转移。底层 ARNO 使用可用液水饱和度 S，
残余液水不排出：q/Dsmax=(Ds/Ws)S+(1−Ds/Ws)[max(S−Ws,0)/(1−Ws)]^c。
由日速率乘实际 dt，限制在可用液水内，再乘既有冻土渗透系数。
不提取冰，不再对 ARNO 人为施加田间持水量截断。出流焓按底层实际温度计算。
这是显式分步算法，长时间步与连续站点结果尚须验证。

NumPy 完整焓柱支持 runoff surface/subsurface 的 (6,6)、(6,3)、(3,6)；
与 TOPMODEL/BATS 的混搭明确拒绝。VIC 分支按真实地表和底部出口报告，
不会只给已流出的水重新贴标签。可传 `vic_parameters=VICParameters(...)`。
原生入口使用分层冠层完整柱；批量参数可为单一参数对象或 (n,6) 参数数组。
旧无雪/共享液水 GPU 过渡入口尚不开放选项6，避免静默使用未接通的物理。

先完成 NumPy 独立公式和守恒，再同步 JAX/CUDA。756 个容量/湿度/形状/
脉冲组合与65位 Decimal 原始公式、独立面积积分对照，最大入渗绝对差
**5.68434189e-14 kg/m²**；非近零最大相对差 **1.44270188e-13%**。
ARNO 独立高精度对照最大差 **1.11022302e-16 kg/m²**。
暖土、冻土、融雪及三组选项共12个完整 NumPy 工况，最大水/焓残差
**7.86037901e-14 kg/m² / 8.37934203e-6 J/m²**。
另验证改变 b 会改变实际土壤储水，改变 Dsmax 只从底层扣去对应水和焓。
最初一个测试错误假定上面两层的差必须超过1 kg/m²，实际为0.985927 kg/m²，
受层间排水影响；改为检查方向和完整柱的独立水量恒等式，没有改物理或放宽守恒。

冻结 `p3-vic-a` 的 NumPy、原生组件及既有土壤输送目标：
**32 passed / 0 skipped，116.94秒**。152个量化输入含三种土质、冻融、
残余液水、饱和/干土及混合开关，CUDA32/JAX32全部输出最大差 **0**。

**1.26121336e-13 kg/m² / 6.98491931e-8 J/m²**。

不用10%替代守恒。原始证据：[A目标日志](v1-results/p3-vic-a-target.log.gz)。
