# P2 多层冠层辐射组件（尚未接入柱驱动）

NumPy实现位于 `physics/canopy_radiation.py`，JAX和CUDA有独立实现。当前提供
10层短波和长波数值组件；叶温、空气温湿以及柱驱动的耦合仍待完成。

短波采用[CLM5技术手册2.3节](https://escomp.github.io/CTSM/release-clm5.0/tech_note/Surface_Albedos/CLM50_Tech_Note_Surface_Albedos.html)
的双流方程，显式区分直射、向下散射和向上散射，包含地表反射后的反复散射。
按公开方程原创实现薄层添加/倍增法：每个物理层先分为1024薄层，再倍增10次。
每层吸收由边界通量差诊断；纯散射极限显式维持反射+透射=1，防止float32
多次倍增产生虚假吸收。没有复制CTSM代码。

当前叶倾角采用球形分布，漫射消光系数1。NumPy双波段包装将可见光与近红外
分别求解；PAR使用可见光吸收量×4.6 µmol/J，再除以该层叶面积，明确区分
每平方米地表和每平方米叶片。默认可见光比例0.5、漫射比例0.5、天顶角余弦
0.5是显式假设，不能当作已测驱动；站点接入时需要相应元数据或有记录的诊断。
NumPy支持逐层光学参数；当前GPU接口为每柱统一光学参数和逐层叶面积。

长波采用无散射灰体近似：有效叶片在热红外视作黑体，双面发射，包含地表
非黑体反射。每层可有不同叶温；返回正/负净吸收及全冠层能量残差。
此简化没有实现PFT叶角差异、叶簇效应、茎光学性质或冠层截雪光学性质。

## 独立参考与检查

`tests/test_canopy_radiation.py` 对36组LAI/太阳角/叶片光学配置建立独立
连续方程参考：SciPy 3×3矩阵指数推进每层，整体边界条件用稠密线性系统
同时求解。参考没有调用生产层系数或添加算法；不是两次运行同一实现。
最大逐层吸收差 **0.05534214 W/m²**，参考绝对值>1 W/m²时最大相对差
**0.140605%**；反射最大相对差0.048004%，地表吸收0.121690%。
NumPy预算最大残差 **3.410605e-13 W/m²**。40项CPU测试也覆盖裸地、
Beer定律、零辐射、纯散射、PAR面积换算、等温长波平衡和非均温长波收支。

短波GPU检查包括432组网格案例与256组非均匀叶面积随机案例；长波另检查
256组随机/等温/裸地案例。实际逐字段偏差、源文件SHA256和设备记录在
`v1-results/p2-component-audit.json`，同精度门始终为1e-6。
最终CUDA32/JAX32的全部输出最大差为**0**。JAX32对同量化输入NumPy64，
短波逐层吸收最大绝对差0.1044269 W/m²，参考>1 W/m²的最大相对差2.44525%；
长波净吸收最大绝对差1.940058e-4 W/m²，最大非近零相对差0.005961%。
短波/长波float32实际预算残差最大为4.882813e-4 / 2.136230e-4 W/m²，
是有限精度加减的收支误差，并非10%科学容差下被豁免的遗漏通量。
最初随机短波差异来自上散射系数的嵌套除法：XLA将0.5/k转换为mu，CUDA
重新计算倒数。显式使用同一代数式消除了差异；对数函数近似不是根因。

复算：`python benchmarks/check_canopy_components.py --gpu --output outputs/components.json`。
这验证组件方程、数值和收支，不能替代CTSM官方整柱输出或FLUXNET GPP评价。
