### 测高假设及敏感性（Wang确认，2026-10-16）

Wang确认没有额外测高记录，采用文献假设并做敏感性分析。已在模型评分前
[锁定方案](v1-results/fluxnet-height-sensitivity-protocol.json)：每站温湿共址高度
与风速高度作3×3组合，温湿/风速不随观测拟合改变。基线长岭温湿6 m、风2 m；
千烟洲均39.6 m；长白山均61.8 m。备选分别2/4/6、23.6/31.6/39.6、
32/49.8/61.8 m。长岭4/6 m风高是显式塔层高度敏感性假设，并非已证实的
风速仪记录。全部方案保留；不选分数最高的高度替代基线。

冠高在该分析内固定为BIF对应的0.43/11/32 m，位移2h/3、动量粗糙度0.1h、
热/水粗糙度0.01h均作为未校准几何假设。高度候选对同一强迫值作不同位置解释，
不叠加第二次高度转换。先以有效风2 m/s、固定L=−100 m/中性/+100 m核查
[81组交换系数](v1-results/fluxnet-height-transfer-sensitivity.json)：相对基线的
热交换速度变化范围长岭 **−27.1486%至+23.1246%**，千烟洲 **0至+79.6023%**，
长白山 **0至+374.7573%**。保持的是Obukhov长度而非不同测高下相同ζ。
这些是规定边界下的系数响应，**不是实际H/LE/GPP/NEE通量变化或站点通过结果**。
特别是长白山32 m方案接近BIF冠顶，暴露MOST粗糙子层近似的限制；下一步完整柱
必须报告全部方案的实际通量/状态响应及测高不确定性，不能只沿用默认2 m。

### 站点太阳几何与短波分解（2026-10-16）

新增`benchmarks/fluxnet_solar.py`供各后端共享预处理输入。显式传入当地标准时、
固定UTC偏移及经纬度；实际驱动应使用每个强迫区间中点。按
[NOAA简化谐波公式](https://www.gml.noaa.gov/grad/solcalc/solareqns.PDF)计算几何
太阳天顶角，年内相位统一用UTC，支持闰年和跨年时区换算。昼长以几何地平线
为准，不混用包含折射的日出/日落。此处不依赖模型后端的默认cosine=0.5。

无实测散射短波时用[Erbs分段关系](https://pvpmc.sandia.gov/modeling-guide/1-weather-design-inputs/irradiance-insolation/direct-normal-irradiance/piecewise-decomposition-models/)
估算比例。该经验关系原为小时尺度，应用到半小时是明确近似，尚无本地散射
辐射观测验收。轨道距离按Spencer公式、太阳常数1366.1 W/m²；低太阳高度
保护取天顶角87°，与[pvlib说明](https://pvlib-python.readthedocs.io/en/v0.10.3/reference/generated/pvlib.irradiance.erbs.html)
一致。低太阳高度或夜间的正短波全部记作散射且返回标志，保留总能量，不静默
将观测归零；原始晴空指数和限制到1的公式输入分别保留。还需站点全时段统计

## 映射、缺失值与 QC

读取列名而非固定列号。根据 `TIMESTAMP_START/END` 求 `dt`，仅接受连续且
等间隔的 1800/3600 秒 HH/HR 数据；缺行、重复、缺 forcing、非法湿度或负降水
均报错，不自动填补。`-9999` 作为缺失值；时间保持当地标准时间，不引入夏令时。
时间/缺失定义见 [FLUXNET2015 dataset](https://fluxnet.org/data/fluxnet2015-dataset/)。

| CSV 列 | Forcing | 转换 |
|---|---|---|
| TA_F，°C | tair，K | +273.15 |
| VPD_F，hPa；或显式 `--humidity rh` 的 RH，% | qair，kg/kg | `es=611.2 exp(17.67 Tc/(Tc+243.5))`；VPD 路径 `e=es−100 VPD`，RH 路径 `e=es RH/100`；`q=0.622 e/(p−0.378 e)` |
| WS_F，m/s | wind，m/s | 原值；本 smoke 未做塔高至模型参考高度校正 |
| PA_F，kPa | ps，Pa | ×1000 |
| SW_IN_F / LW_IN_F，W/m² | swdown / lwdown | 原值 |
| P_F，每条记录的 mm | prcp，m/s | `/1000/dt`，不是 mm/s 或日降水 |

单位与 consolidated `_F` 定义来自
[官方 FULLSET 变量表](https://fluxnet.org/data/fluxnet2015-dataset/fullset-data-product/)。
VPD 和 RH 为显式替代路线，默认 VPD，缺值时不静默切换。
湿度计算使用普通版相同的水面 Tetens 约定；不把不同饱和水汽压公式造成的不一致
隐藏为裁剪。真实月份所有必需 forcing 有值：TA/VPD/WS/LW/P 的 QC 均为 0；
PA 有 1 条 QC=2（ERA），SW 有 1 条 QC=1（良好填补），其余均 QC=0。
这些已有产品 gapfill 作为 forcing 使用并完整计数，不称全观测强迫。

LE/H 使用未做能量闭合校正的 `LE_F_MDS/H_F_MDS`，仅有限且各自 **QC=0** 的
记录进入观测指标。LE 为 1360/1440、H 为 1414/1440；不要求二者同时有效，
不把 gapfill 当作实测。bias 定义为模型减观测；相关系数无方差时记 null。
QC 与通量产品含义见 [Variables quick start](https://fluxnet.org/data/fluxnet2015-dataset/variables-quick-start-guide/)。
档案文件版本为 `1-4`，该月份 LE/H QC 无缺失；历史 QC 缺失问题见
[Known issues](https://fluxnet.org/data/fluxnet2015-dataset/known-issues/)，不可把别的月份缺 QC 自动当 0。
