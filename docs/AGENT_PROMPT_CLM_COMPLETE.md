# 给接手本仓库的 AI Agent 的工作指令（阶段 5：CLM 完整开发，v1.0.0）

> 这是一段可直接粘贴给另一个 AI agent 的 prompt。那个 agent 持有 Wang 的 GitHub 凭证。
> 背景：v0.2.0（GPU 移植收尾）已合并 main 并发布；`docs/GPU_ACCEPTANCE.md`
> 记录了 Wang 对已知限制的验收。**本阶段的目标是 CLM 单柱物理的完整开发**，
> 不是 GPU 移植。开工先读 `README.md`、`ROADMAP.md`、`docs/KNOWN_LIMITATIONS.md`、
> `docs/FLUXNET_PLAN.md`。

## P0. 目标与验收口径（Wang 已确认，先读）

1. **目标**：CLM 单柱物理完整开发，发布 `v1.0.0`。
2. **验收口径：5–10% 误差可接受。** 具体化为：关键变量
   （日/月累积 ET、H、LE、GPP、NEE、土壤温湿、径流、积雪 SWE）
   与参考（CLM5/CTSM 官方输出、Noah-MP HRLDAS 输出、FLUXNET 观测）对比，
   相对偏差 ≤10% 即通过；瞬时通量要求 r > 0.85；近零量用绝对容差
   （不许用相对误差卡近零量）。
3. **旧的 1e-4 级逐元素门全部退役**：H4/K3/M4 的红灯转为"已接受的已知限制"
   （历史记录保留在 `docs/`），**不再作为本阶段合并条件**。
   不要再为 1e-4 级差异耗时间——那不是本阶段的验收标准。
4. **"全部开发"的范围界定**：单柱抽象内的完整陆面过程
   （生物地球物理 + 生物地球化学 + 主要扩展过程）。
   **不包括**：整机 CESM/WRF 耦合、河道演算、侧向地下水、
   土地利用变化、城市模型（CLM urban 是独立子系统，超出单柱范围）。
   这些若要做，是另一个项目，不要在本阶段展开。
5. 每个新物理模块：先 NumPy 参考 + 单元测试 + 与参考对比在 10% 内，
   再同步 JAX + CUDA（同样 10% 档内验证），保持 v0.2.0 的多后端结构。
6. 每 2 小时 push；单点阻塞 30 分钟记 `docs/GPU_BLOCKERS.md` 并绕行；
   报告**实际偏差数字**，不许只写"通过"。

## P1. 先修已知物理缺口（约 1–2 天，收尾遗留）

1. **融雪后热量路由缺口**（`docs/GPU_ANNUAL_FIX.md` 已记录）：
   完整融尽后剩余能量未路由。修：能量守恒是硬要求，
   不受 5–10% 口径影响（守恒问题不是精度问题）。修完重跑 365 天。
2. **冻土 AHC 截断放大**（K3 遗留）：无雪砂土冻融中，AHC 未冻水截断区
   把 0.00066 K 的旧态温差放大至 0.194 K。修：平滑截断逻辑，
   验证 5529 柱类问题缓解（10% 口径内）。
3. **厚雪下均温土壤漂移**（K3 遗留，36 柱）：float32 Thomas 漂移。
   **注意：M1 的 ΔT 全量方案已试过，因同精度回归而回退（见
   `docs/GPU_DELTA_ATTEMPT.md`），不许重复同一方案。** 若再攻，
   先定位回归原因，或用 Kahan 求和等局部缓解；搞不定则记为已知限制。
4. **近零 canw（M4）**：46 项超差，最大绝对差 2.65e-8 m——
   在 5–10% 口径下已可接受，**不修**，只需确认
   `docs/KNOWN_LIMITATIONS.md` 已标注"已接受"。

## P2. CLM 生物地球物理核心（Phase 2，主体，约 3–5 天）

CLM 区别于 Noah-MP 的核心部分，目前完全未实现：

5. **多层冠层（~10 层）+ Farquhar 光合 + Ball-Berry 气孔耦合**，
   替代现有 big-leaf 经验光合曲线。参考 CTSM `CanopyFluxes` /
   `Photosynthesis` 模块结构（只读理解，不复制代码）。
   每层：光合（Farquhar：Rubisco 限制 / RuBP 再生限制 / TPU 限制，
   取最小）、气孔导度（Ball-Berry）、叶温。
   验证：单叶光响应曲线与文献值对比在 10% 内；冠层 GPP 与
   FLUXNET 观测对比 r > 0.85。
6. **冠层分层辐射（双流近似）+ 植被能量平衡迭代**
   （Phase 1 遗留）：每层吸收/反射/透射短波，逐层能量平衡，
   替代现有 big-leaf 辐射近似。
7. **冠层空气空间**（温湿，简化版）：冠层内空气温湿诊断，
   用于叶—气交换。
8. **5 层雪**（CLM 最多 5 层，从现有 3 层扩展）+ **SNICAR 雪反照率**
   （`OptSnowAlbedo=3`，简化版：黑碳/尘埃沉降用气候态输入，
   不做完整气溶胶传输）。

## P4. CLM BGC：碳氮循环（CLM 的标志性部分，约 3–5 天）

目前完全未实现；没有它，CLM 不能叫完整：

    温度/水分调节函数；参考 CTSM `SoilBiogeochemDecompCascade` 结构）。

    （缺氮时下调 Vcmax）。

    验证：GPP/NEE 与 FLUXNET 观测对比在 10% 内或 r > 0.85；
    土壤碳库长期 spinup 后达到准平衡（漂移 < 5%/百年量级可接受）。
