## 相变坐标与守恒

既有混合相焓方程只覆盖“原本有凝结水”的叶层。本次将同一物理平台扩展到
原无水、正在融点附近接收水汽的叶层。启用条件为正在凝结且干叶温度距Tf
不超过0.05 K；这个范围只切换未知量坐标，不平滑温度、改潜热或加入初始水。
在新坐标z中，温度及新凝结水液态比例为

`T = Tf + min(z,0) Cw/Ci + max(z−Lf/Cw,0)`，

`α = clip(z Cw/Lf, 0, 1)`。

平台内T精确等于Tf；α由逐层能量和空气水量共同决定。原有水层继续按原焓
决定比例，未接近融点的新干叶继续使用温度坐标。若没有实际凝结且水量为零，
冗余平台坐标按原热残差方向移到边缘，让叶温继续响应。所有试探仍满足原
残差门，未改变最大迭代数。NumPy、JAX及CUDA均实现相同坐标切换。

饱和水汽压按α加权冰/水表面，凝结潜热仍为`Lv E + Lf Eice`，新水携焓
单独记账。原无水时热试探库存H*=0，末态新水的焓与水汽携焓严格相抵；
`H_new + A = 0`。任意平台比例的“水汽携焓＋释放潜热”仍为每kg的`Lv+Lf`。
没有在迭代或失败后补加水热。

这是本项目联立焓方程的守恒扩展。[CLM5冠层水说明式2.7.19—20](https://escomp.github.io/CTSM/release-clm5.0/tech_note/Hydrology/CLM50_Tech_Note_Hydrology.html)
采用T>Tf液水、T≤Tf冰的温度切换，本实现并不声称逐项复现该开关；混合暴露
比例及新水在平台内的处理仍需实际冠层冰雪观测评价。
