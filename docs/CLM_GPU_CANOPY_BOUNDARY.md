# 固定雪/土表温的冠层能量边界

2026-10-14：新增 `gpu.canopy_boundary` 与 `gpu.cuda.canopy_boundary`。
NumPy 参考仍为 `physics.canopy_energy.solve_canopy_energy`，其固定雪面和
冠层液水储热的独立方程检查已在此前完成。新入口把这些过程同步到原生
JAX/CUDA，用于下一步连接完整冬季质量/焓柱；当前仍是边界组件。

## 物理与接口

十层叶片的叶温、Farquhar/Ball–Berry 和诊断冠层空气温湿联立。调用者
提供固定地表温度，地表净辐射减去感热、潜热后得到可供雪/土壤的热通量，
不再以预设地温梯度替代真实柱焓变化。冰面使用 Murphy–Koop 饱和水汽压
及 Lv+Lf；液面使用现有液水公式。雪的蒸发供水与土壤根水可独立设置。

短波在设备上连接冠层双流与 SNICAR，返回五层雪和土壤的分别吸收量。
`ground_nonshortwave_heat` 只含地表非短波热量，调用者要把它和逐深度
短波分别送给共享导热求解器，不能把雪下吸收全部加在雪表层。

冠层液水存量以质量和焓输入，最终质量由实际湿叶汽化/凝结更新，储热
温度使用叶面积权重。每层湿叶汽化携带液水焓；根水到叶片之间的焓差
进入叶能量方程。诊断同时给出储水变化、湿叶携热、蒸腾携热和逐根取水，
便于上层把汽化潜热与液态水携热分别核算。

`pack_canopy_boundary` 只编码参数，不调用 NumPy 物理产生设备结果。
原五组冠层输入后增加固定边界/储水数组、五层雪光学状态和有效雪层数。
`run_canopy_boundary_jax/cuda` 返回与 NumPy 同名的诊断；雪吸收固定补齐
到五层。无效储水、超供水上限、非法冰面温度和未收敛均明确报错。

## 极薄叶层的定位

初版扩大检查在第 320 个输入的第二叶层失败：LAI **0.002099599**，
植被比例 **0.2861716**。NumPy64 叶温 **278.103661 K**，JAX32 为
**278.186401 K**，差 **0.082740 K**，超出预设 0.05 K 组件检查线。
收紧迭代残差到 0.001 或 0.0005 W/m² 后仍为 **278.186707 K**，
因此没有把问题归咎于未充分迭代。

该层短波吸收为 **0.2609753 / 0.2544518 W/m²**（设备/NumPy），
差 **0.00652346 W/m²**；PAR 为 **1352.2534 / 1338.1651 µmol/m²/s**。
固定十次倍增中，接近 1 的透射率舍入被放大，随后大通量相减进一步
影响很小的叶层吸收。原日志、探针和固定输入均保留。

新边界使用吸收量的直接递推。设薄层漫射吸收为 A、直射吸收为 B，
漫射反射/透射为 r/t，直射散射向上/下为 u/d，直射透射为 b；两个
相同层叠加时使用

```
A' = A * (1 + t/(1-r))
B' = B * (1+b) + A * (d+u*b)/(1-r)
I' = I * (2-I)                 # I = 1-b，直接递推小截获量
t' = 1-r'-A'
d' = I'-u'-B'
absorbed = A * (diffuse_down_top + diffuse_up_bottom) + B * beam_top
```

这与原被动薄层的线性收支方程等价；没有增加吸收或放宽温度、科学门。
`track_absorption=True` 用于新固定边界，已有独立辐射/无雪入口保持原
求值路径并做回归。修后目标工况含上述保存输入，55 组最大叶温差
**0.002555932 K**，CUDA32/JAX32 所有输出最大差 **0**。

## 核验状态与边界

目标工况涵盖 250 K 冰面到暖土、零/部分/完全植被、供水不足、湿叶、
凝结、空雪与五层雪。7 组另对照独立 SciPy 同时解叶温/空气湿度方程。
科学比较用同量化输入的 NumPy64；温度纯绝对 0.05 K，不除以绝对 Kelvin。
通量/水量使用预先固定的分段近零门，同精度保持 `rtol=atol=1e-6`。
水量、储热及携热预算独立检查，不用 10% 豁免守恒残差。

扩大检查为 **425 个工况**（24 个具名、400 个随机、1 个保存的极薄叶层
