# 联合热量求解的局部舍入恢复（2026-10-17）

四站冷启动气候年冻结E通过原262步故障位置，在325个完整步后于千烟洲
2003-01-07 18:30再次停止。表面点残差2.35438e-6 K已经满足原温度门，
实际失败是联合热量的雪层方程：残差0.0733566284 J/m²，原界0.0722199902，
归一化1.015738606。其他土层方程均在原界内；不能用10%口径豁免此失败。

[独立参考和运行节点/PBS收据](v1-results/heat-coordinate-reference-and-cold-week/manifest.json)保留。

隔离实验表明，原耦合Newton线搜索不接受方向时，只沿最差归一化方程作局部
Newton修正，可以关闭该方程。雪焓从−20.2379684448变为−20.2380599976 J/m²，
只差9.15527e-5 J/m²，残差降至0.00116729736、归一化0.0592108816。
大邻层焓的float32网格阻碍耦合方向是与该实验一致的解释，未完整追踪所有邻层
增量，故不将其写为已独立证明的唯一原因。

JAX/CUDA现仅在原40次耦合线搜索不接受时启用该恢复：选取最差活跃层，用原
Jacobian对角元修正，保留冰水相变端点落点和最多40次回退。接受仍要求原加权
残差下降或原归一化≤1，外层80次上限不变。NumPy物理和热量参考均未改；
没有重试M1全量ΔT、提升设备精度或放宽任何收支/收敛界。
