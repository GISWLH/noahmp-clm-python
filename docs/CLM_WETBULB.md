# Wang 2019 湿球降水相态（开发中）

依据 [Wang et al. 2019](https://doi.org/10.1029/2019GL085722) 的式(1)、(2)
独立实现；原文开放版本由 [NOAA保存](https://repository.library.noaa.gov/view/noaa/54993/noaa_54993_DS1.pdf)。
已查看论文第3、4页的方程及图1。相态函数为
`fs = 1 / (1 + 6.99e-5 exp(2(Tw_C + 3.97)))`，系数须配合摄氏温度；
正文将Tw标为K，与图1横轴及系数不一致，不能直接把Kelvin代入该指数。

湿球温度求解 `es(Tw)-eair + gamma*(Tw-Ta) = 0`，Ta固定；
`es=610.8 exp(17.27 Tw_C/(237.3+Tw_C))`，`gamma=Cp*p/(0.622 L)`。
使用项目一致的Cp=1004、Lv=2.5e6、Lf=334000；Ta>273.15 K取Lv，
否则取Lv+Lf。液面Tetens饱和曲线及按气温选择潜热是本方案的明确近似。
二分求解单调方程，支持超饱和输入，不裁去湿度或在8°C强制截为雨。

参考差异必须保留：论文式(2)下方的文字称迭代至`es(Tw)=eair`；这会得到
露点而非该式的湿球解。[当前官方AtmosForcingMod](https://raw.githubusercontent.com/NCAR/noahmp/master/src/AtmosForcingMod.F90)
也从上一次Tw减去压差项，并在8°C以上强制全雨，未固定式(2)右端的Ta。
本实现以明确的式(2)热力学关系为准。因此**不宣称复现该官方迭代或图1(a)**，
官方相态及整柱输出对标仍需分别报告差异；不可将独立方程对照冒充官方验收。
