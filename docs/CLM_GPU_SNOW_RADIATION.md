# 五层雪辐射与冠层短波：原生 JAX/CUDA

2026-10-14：五波段 SNICAR 近似及十层冠层—雪短波边界已同步 NumPy、
JAX64/32 和 CUDA32。Linux 全量 **460 passed / 0 skipped，278.97 秒**；
目标测试 **11 passed / 0 skipped，25.12 秒**。这是方程、数值和后端验证，
不等于 CTSM 官方整柱输出或积雪观测验收。完整冬季柱和雪水文 GPU 尚未完成。

## 接口与范围

`gpu.snicar` / `gpu.cuda.snicar` 的批量入口分别为
`run_snow_shortwave_jax` / `run_snow_shortwave_cuda`。每柱最多五层，
保存质量、粒径、亲水黑碳和四类尘埃质量；边界包含可见光/近红外的
直射/散射、两类地面反照率和太阳天顶角余弦。粒径超出 30–1500 µm
查表范围时截到端点，并输出逐层标记。夜间反照率未定义，输出数值零
并设 `albedo_defined=False`；这不意味着夜间实测反照率为零。

UCAR 查表数据来源及许可见[雪设计记录](CLM_SNOW_DESIGN.md)。表格作为
常量传到设备；插值、杂质混合、delta 缩放、三通量薄层矩阵指数、
逐次倍增、层间多次反射及收支计算都在设备执行，没有 host 物理回退。
可见光采用 Eddington 闭合，近红外采用半球平均闭合。直/散射分别查表，
近红外沿用 NumPy 的固定四波段权重。

`gpu.canopy_snow_radiation` / `gpu.cuda.canopy_snow_radiation` 用两类
单位入射的雪响应得到直射及散射雪反照率，连接十层冠层双流方程。
根据实际穿透冠层及裸地部分的向下通量线性缩放雪响应，返回叶片、
五层雪、土壤吸收和柱顶反射。冠层底部直/散射反照率分别处理。
原先只有一个地面反照率的冠层入口保留原运算路径。
当前雪覆盖整个柱底，部分雪覆盖、雪面能量迭代及水文演化另行连接。

## 薄层弱吸收的失败与修复

扩大工况后，初版五层样本第 2 层可见光吸收出现 **13.5502676%** 偏差：
同量化输入 NumPy64 为 **1.4274116256 W/m²**，GPU32 为
**1.2339935303 W/m²**。原输入保存在
`tests/fixtures/snow_weak_absorption.json`，旧结果和日志继续归档。
该层质量约 15.7053 kg/m²、粒径落到 30 µm 查表端点、光学厚度约 874，
单次散射反照率接近一。薄层中两个接近一的量相减损失了微小吸收信号，
随后倍增放大误差。

修复为在三通量方程旁同时积分吸收行。令 delta 缩放后的吸收比例为
`ell=(1-omega)/(1-omega*g*g)`，则
`A' = 2*ell*(D+U) + ell*B/mu`。薄层先直接积分吸收，再由反射及吸收
构造透射；倍增时同时累加吸收。该形式与原方程等价，没有事后修改
收支或把整个 CUDA 内核改成双精度。

中间版本又发现 CUDA/JAX 同精度差异：3×3 传递矩阵相同，而吸收源行
第三分量相差 1.490116e-8，最终近零通量差超过 1e-6。单独增加除法后的
舍入屏障仍失败。改为复用已舍入的直射矩阵项 `-ell*small[2,2]` 后消除
普通量级差异；未做编译器反汇编，不能把具体优化指令当成已证实根因。

还修正了初版检查器：`rtol=.1, atol=.1` 会让非近零的 13.55% 偏差
误过门。现在采用分段门，通量参考绝对值大于 1 W/m² 时只用 10% 相对门，
否则只用 0.1 W/m² 绝对门。PAR 同样按 1 µmol/m²叶/s 分界；反照率
按 0.001 分界、近零绝对容差 1e-6。CUDA32/JAX32 始终保留
`rtol=atol=1e-6`，没有随着科学门放宽。
