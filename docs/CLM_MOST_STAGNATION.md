# 千烟洲稳定边界层浮点二分停滞

2026-10-17，千烟洲冷启动整周LE低估64%—73%，而固定测高扰动只能解释
−1.7%—+4.1%的响应。根区水分胁迫是另一个可检验因素：原初始化将浅层实测
`0.137 m³/m³`扩展至全部2 m土柱，初始根权重胁迫因子仅`0.10625`，叶氮因子1。
这不是深层水分实测，也未经过气候spinup。

## 同态重放与根因

逐组从同一个已保存末态重放，仅“名义土壤、深层田间持水量”CUDA失败。
其余三组分别11、12、15次收敛。四组同量化输入的NumPy参考都收敛，失败组
参考用11次：H=`−0.4880494243 W/m²`，LE=`3.7325250520 W/m²`，系数残差
`3.93081103e-5`。这不是物理状态无解，也不是旧H4/K3逐元素门。
