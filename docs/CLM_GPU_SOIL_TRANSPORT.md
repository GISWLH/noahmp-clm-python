# 土壤质量与随水迁移的焓：原生后端

2026-10-14：新增 `gpu.soil_transport` / `gpu.cuda.soil_transport`，同步
已有 NumPy `soil_enthalpy.infiltrate`、`withdraw_liquid` 和
`soil_drainage.drain_soil`。固定四层，每层水质量 kg/m²、焓 J/m² 和厚度 m。
这些是完整新柱所需的质量/热量转移过程，不代表完整冬季柱已经接通。

## 过程与接口

`pack_soil_transport` 编码三个模式，`run_soil_transport_jax/cuda` 在
设备上完成所有相态反演和物理计算；没有用 NumPy 物理生成 GPU 结果。

1. 入渗：按现有液态水当量孔隙容量，自上而下接收输入质量及其比焓，
   未接收部分连同焓作为出流返回。输入焓可包含冰或水的显热/融化潜热。
2. 取水：按给定的逐层液态水需求，移除实际质量及
   `mass * (Lf + Cw * (T-Tf))`。该携热项与大气汽化潜热分开处理。
3. 排水：Campbell 导水率、田间持水量阈值和现有冻土渗透选项；逐层
   更新质量与焓后，再反演下一层相态。受源液水和接收层容量限制，
   返回逐界面质量/焓和底部出流，内部转移不能重复记为柱外通量。

相态使用已经验证的[土壤焓反演](CLM_GPU_ENTHALPY.md)，焓为权威状态，
不会以反演温度重新生成并覆盖它。给定取水不超过水质量；液水可用量的
判断允许 8 epsilon 的反演舍入界，但不截改请求量。真正过抽、非有限
输入或超出 150–400 K 热力学域均报错，不能让无效状态继续推进。

每个模式输出入流、地表出流、根系取水、层间输送与底部出流的独立账目。
NumPy 的液态水当量容量约定保持一致，未声称已处理土壤孔隙内全部冰胀
几何。这也不是 Richards 垂向水流或 VIC 产流方案；这些边界继续明确保留。

## 验证口径与首轮记录

目标检查涵盖砂/壤/黏土、250 K 深冻结、近融点与暖土、两种未冻水及
冻土渗透选项、零水、饱和、完全取尽液水和大入流溢出。NumPy 原有温度
反演另有独立 Brent 求根，暖土排水有解析通量检查，守恒从输出独立累加。

初版把所有输送焓都按 1 J/m² 分界和 0.1 J/m² 近零差检查，在饱和土层
的极小排水中报错：某界面 NumPy 为 **6.743759 J/m²**，float32 为
**11.066681 J/m²**，差 **4.322922 J/m²**；其他两个微小界面为
**0 / 0.6484383** 和 **0 / 1.296877 J/m²**（设备/NumPy）。这些来自
容量减存量的 float32 舍入，半小时最大携热通量差为 **0.002401623 W/m²**。

这次修改了验证脚本的单位处理：输送焓按项目已经确定的
[V1_ACCEPTANCE.md](V1_ACCEPTANCE.md) 热通量近零标准，转换为步长积分。
即 `|energy/dt| <= 10 W/m²` 时，绝对差限值为 `dt * 1 W/m²`；
其余用 10% 相对差。水质量仍以 0.001 kg/m² 分界、0.0001 kg/m²
绝对差检查，温度用纯绝对 0.05 K，CUDA32/JAX32 保留 1e-6 同精度门。
原不合适的焦耳级检查及其失败日志保留，没有修改物理以贴合该检查。

质量与总焓守恒使用独立 double 累加，按每层有限次加减的 16 epsilon
存量/边界量界核对，完全独立于上述科学误差门。不会把 10% 直接用于守恒。

## 实测记录

目标 152 工况：**6 passed / 0 skipped，20.41 秒**。同精度所有状态和
质量/焓账目最大差 **0**；float32 对同量化 NumPy64 最大温差
**2.416764e-5 K**、液水差 **8.702848e-5 kg/m²**、冰差
**8.171221e-5 kg/m²**。界面质量差最大 **1.192093e-5 kg/m²**。

连续轨迹另一次原始逐元素检查报出 **0 对 0.001511365 kg/m²**。
字段复核为微量土壤冰量，并非层间排水；初始终端摘要没有打印字段名，
执行过程中曾误判，后已纠正。它来自独立舍入历史的相态差，不能把用于
同一输入的组件质量门直接套在连续土壤湿度上。
最终连续检查按 P0 的既定单位核对：水/液水/冰分别换算为体积含量，
近零界 0.02 m³/m³、绝对容差 0.002 m³/m³；温差仍用更严格的 0.05 K。
逐日输送质量按 0.5 kg/m²/day 分界、0.05 kg/m²/day 绝对差，逐日携热
按 10 W/m² 分界、1 W/m² 绝对差。所有非近零量保持 10%。
原组件门在连续轨迹上的失败数量、首个完整输入/状态和逐步最大差继续
随报告输出，不把它们改写成原门通过。同精度和每步/累计守恒另行核对。

裸土霜/零焓冰/液水的补充 27 工况：温差最大 **2.034690e-5 K**，
