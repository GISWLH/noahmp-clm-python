# 分层冠层冰水接入完整焓柱（开发中）

`CLMColumnState.with_layered_canopy()`将已有冠层总质量/焓保守分到十层；
已有分层状态不会被隐式重新分配。每层质量与焓是权威状态，旧标量字段
仅为总量别名。质量/焓决定冰水比例与温度，包括完整融化平台。

NumPy柱步骤已连接降雨/降雪截留、叶温和冠层空气联立、地面水汽、根水携热、
雪—土壤传热、融水入渗及重力排水。降水在步首截留，卸载分别推进两个半步；
步末重新处理因相变/凝结超过容量的液水滴落和冰雪卸载。冰水出流各自携带
实际焓进入地面雪/土壤，根水携入是柱内转移，蒸腾携出是外部热通量。
冠层冰升华的熔化潜热单独进入LE，避免沿用纯液水的LV造成热量缺口。
