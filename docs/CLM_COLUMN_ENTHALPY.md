# 雪—土壤焓与冬季冠层边界

2026-10-14 NumPy开发检查点。`column_heat.coupled_heat_step`已将五层雪与土壤放入
同一个隐式能量系统；融水携带的热量也已实际加入土壤。冠层已提供固定雪面

## 状态与方程

`soil_enthalpy.SoilEnthalpyState`保存逐层水当量质量、焓和厚度。以273.15 K的
干土与冰为零点，液水包含334000 J/kg的熔化潜热：

```text
H = [(1-porosity)*2e6*dz + 2100*water + (4180-2100)*liquid]*(T-273.15)
    + 334000*liquid
```

质量为kg/m²，厚度m，焓J/m²。液水曲线沿用已经平滑的冻土选项1/2，包含
选项2的三次固定更新；新增解析导数只用于焓反演和隐式求解。反演使用有界
Newton；150–400 K是输入域检查，超域报错，不截断能量。土壤总含水量仍按
水当量体积限制，尚未新增土壤力学冻胀模型。

联合传热采用旧态导热率、后向Euler和绝热土壤底边界，每个雪—雪、雪—土、
土—土界面只有一个共享通量，分别以相反符号进入相邻储库。雪使用密度型
导热率，土壤保留现有Johansen近似；没有修改发布路径的AHC/Thomas实现，
也没有重试M1的全量ΔT重写。

相变平台端点使用单侧导数和相变事件步长。初版全年案例在第301天的
0.362957725 kg/m²薄雪融尽点停滞，残差69894.7295 J/m²：从潜热平台出发
的线搜索无法跨到液态热容分支。修复后同一保存状态3次迭代收敛，收支差
−8.149073e-10 J/m²，独立MINPACK解也已核对。原失败日志归档于
[历史失败](v1-results/p2-column-enthalpy-earlier-failure.log.gz)，输入保存在
`tests/fixtures/column_phase_boundary.json`，未放宽守恒门。

`infiltrate`按剩余孔隙逐层接收质量及其比焓，溢出带着原比焓离开；
`withdraw_liquid`按实际液水温度输出显热和熔化焓。它们是保守转移原语，
**尚非最终入渗、VIC径流或重力排水方案**。大气潜热单独记在热边界，
不把平流焓和潜热混为一项。零质量非零输入焓、超取液水均显式拒绝。

## 冠层—雪边界

`canopy_snow_radiation.canopy_snow_shortwave`从SNICAR取得直射与散射的两波段
有效反照率，冠层添加法包含往返反射，再将冠层底部直/散射送入雪层。
输出逐叶、逐雪层和土壤吸收。近红外子波段仍采用SNICAR的规定权重，
冠层散射后的谱形变化未显式追踪；雪覆盖该柱的植被和裸地部分，暂无部分
雪盖面积参数化。9个异直散反照率工况对独立矩阵指数边值解，最大通量差
0.02162751 W/m²、最大相对差0.0250854%，收支差2.700062e-13 W/m²。

`solve_canopy_energy`新增固定地表温度边界；此时只求叶温，返回可用于
真实储热层的`ground_heat`及扣除短波后的热输入。地表能量被分配出去
不等于已经验证整柱储热，调用方必须与联合焓变化相配。冰面使用
Murphy–Koop冰面饱和水汽压及Lv+Lf升华潜热；冰面供水可与土壤根水分离。
叶表仍用原液水方程，冠层截雪/冻结尚待实现。GPU输入打包器遇到新增冬季
参数显式报未实现，防止静默回落成无雪物理。

[冬季边界原始报告](v1-results/p2-winter-boundary-audit.json)由
`benchmarks/check_winter_boundary.py`生成：60个随机固定雪面工况，独立
有限差分SciPy联立叶温与空气湿度，最大叶温差1.046726e-5 K、H差
1.018974e-4 W/m²、LE差1.272190e-5 W/m²、地表可用热差3.501519e-5 W/m²、
GPP差4.247050e-6 µmol/m²/s；最多15次迭代。最大逐层能量残差
4.904531e-5 W/m²、总表面残差1.672169e-4 W/m²、空气热残差
4.547474e-13 W/m²、水汽残差1.467485e-17 kg/m²/s。
