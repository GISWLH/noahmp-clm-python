## 全部153个超差的归因

153 项对应23个唯一配置×步，全部位于降雨停止后的第24–48步，无雪、无新降雨。
超差时两端冠层水均不超过 **1.22539916e-8 m**；132项属于冠层持续干燥后
极小余量的相对敏感性，21项涉及蒸发被剩余冠层水上限截断后的耗尽舍入。

仪器用原 NumPy64 冠层公式重算每项，并将误差精确分成：float32评价/舍入、
温度轨迹、前态冠层水轨迹、参考公式复算。四项重组误差为0；参考复算最大误差
4.81482e-35 m。前三项最大绝对值分别为 1.37799e-13、4.51697e-12、
9.55421e-12 m（来自不同元素，不应相加冒充同一最坏项）。这提供逐项数值解释，
没有把情景标签当作因果证明，也没有增加状态绝对容差来抹去失败。

| 指标 | CUDA32 / JAX32 实测 | 固定门 |
|---|---:|---:|
| 自身 residual 绝对值中位数 | .000293731689 W/m² | <.001 |
| 自身 residual 绝对值 p99 | .001819610596 W/m² | <.01 |
| 自身 residual 绝对值最大值 | .002484321594 W/m² | 报告值 |
| residual 对 NumPy64 最大差 | .002507086880 W/m² | 报告值 |
| 表面代数闭合最大差 | 2.83718109e-5 W/m² | 预定舍入界内，最大界比 .0177572 |
| 逐步水平衡最大绝对误差 | 6.82770915e-8 m | 预定舍入界内，最大界比 .0123352 |
| 48步累计水平衡最大绝对误差 | 1.13016623e-6 m | 完整报告，有符号逐柱值存JSON |

表面代数闭合与实际 residual 是两个检查。整柱融雪热量缺口依旧存在，Wang 已明确
同意作为已知限制保留；这里不声称整柱焓守恒通过。

原 H4 的48步仍有 H 1461项、LE 6项、G 18864项、residual 49145项超原门。
其中 residual 差>.002 W/m² 仍569项。这与旧mixed原型的137项是不同版本/口径。
