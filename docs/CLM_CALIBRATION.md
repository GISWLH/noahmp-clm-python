物理模型、spinup、灵敏度计算或评分，不能记作校准完成。生产物理仍是已集成的
NM；当前 CUDA1 年度和完整回归的参数、源及累计账没有变化。

[执行成本复核](v1-results/calibration-execution-budget-review/manifest.json)确认，
当前默认组织为23个候选各8柱，共184条独立初态链。五个共享叶参数候选原则上
可合为40柱、使总批数降为19，但还需唯一运行标签到原候选／配置的显式映射；
40柱的耗时和内存尚未实测。若每根先20个初始化年，再加两完整训练年，条件
成本是4048柱年、70,929,792个半小时柱步；这尚不包括SOC额外验证、留出和
测高敏感性，也不代表原20周期限制或总预算已冻结，不能据候选数承诺几天完成。

评分外层现决定四种干湿初态／BGC映射组合各占1/4，全部四组各12训练单元
都有效才计算总损失，不挑最佳组合。评分数学与参考读取已经验证，生产评分入口
仍关闭，尚无实际候选得分。
慢碳库初始化拟先研究真实完整季节驱动下的正常速率条件解，再做含实际氮限制
的重放和完整耦合验证；新冷态库存必须显式记录，不能冒充旧检查点续算。
该方法尚未采用，20次水热循环或一次代数周期解均不等于SOC准平衡。

## 评分器的实际超算验证

[OO完整证据](v1-results/fluxnet-calibration-score-oo/manifest.json)记录EHPC
**1599.manager真实F0**，compute002上28项测试全部通过，测试25.883秒、完整
worker38.931536秒。包含12项数学测试、9项合成状态包测试及7项真实ON参考
集成测试；原观测容器、NM584与控制文件执行前后保持。另有
[主代理对原始日志和归档的独立复核](v1-results/fluxnet-calibration-score-oo-closed-root-review.json)。

| 独立数值核对 | 最大绝对差 |
|---|---:|
| H／LE／NEE归一RMSE与Decimal oracle | 0 |
| 原ON全部12单元、合成零预测与独立总体矩公式 | 2.220446049250313e-16 |
| 四组固定权重的合成总损失与独立汇总 | 0 |

这些数字验证计分程序；所有预测都是明确的合成数据，不是物理候选结果。
固定目标为每组12训练单元等权的归一RMSE，外层四组各1/4；尺度为原ON总体
标准差与固定绝对下限的较大值（H／LE为1W/m²，NEE为0.1umol CO₂/m²/s）。
只用该观测字段自身有限值且QC=0的原掩码，不按模型预测改变覆盖；缺少任何
单元或组合均不能删掉或重分配权重。NEE区间gC除以实际dt和12.0107e-6转换为
原速率，正值表示向大气排放。Cng2007前四个月无QC0的限制完整保留。

合成状态包检查23个检查点字段、22个非索引字段接续以及首步16数组状态。
它只验证解析与拒绝错误状态的行为，不提供真实状态链或守恒证据。生产入口
明确拒绝计分，待实际初始化、各候选自己的spinup和完整交付接入后再启用。
原日/月10%门、瞬时r、近零绝对容差、GPP偏差或r口径及硬守恒仍单独评价。
