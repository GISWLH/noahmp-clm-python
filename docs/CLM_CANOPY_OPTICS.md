# 显式叶片／枝干双波段光学

2026-10-19开发记录。PFT光学输入已连接NumPy、JAX、CUDA的冠层短波、雪地多次
反射、相变能量、MOST、结构化BGC及站点驱动；默认`canopy_optics=None`保留
原泛型路径。新增功能不代表v1.0.0已完成或已发布。

`CanopyOptics`保存可见光／近红外的叶片反射、透射和枝干反射、透射四对参数。
每个组织必须满足0≤ρ、τ≤1及ρ+τ≤1。逐层按叶面积与枝干面积加权散射系数；
总吸收仍用于冠层加热，光合PAR只取叶片吸收，按实际叶面积换算。
枝干可以吸热，但不产生光合PAR。算法沿用现有连续双流近似与球形叶倾角；
参考[CLM5技术说明的面积加权公式2.3.11–12](https://escomp.github.io/CTSM/release-clm5.0/tech_note/Surface_Albedos/CLM50_Tech_Note_Surface_Albedos.html)，
没有复制CTSM源码。叶、枝分别吸收的两波段诊断均保留。

站点JSON可显式传入下列原PFT1参数，单位为无量纲分数；这里是输入示例，不是
根据通量评分选出的新默认值：

```json
"canopy_optics": {
  "leaf_reflectance": [0.07, 0.35],
  "leaf_transmittance": [0.05, 0.10],
  "stem_reflectance": [0.16, 0.39],
  "stem_transmittance": [0.001, 0.001]
}
```

该选项要求分层冠层。原19个主状态和26个保存字段不增加光学状态；参数作为
动态设备输入。辐射原584字段前缀保留，新增40字段分别保存叶／枝的2×10层
吸收；原PAR字段在显式光学分支具有上述叶片定义。CUDA传旧核的584前缀会
显式连续化，避免624列行跨度误读；同精度检查覆盖全部624原始字段及整数标志。

## 参考与工程验证

[原NumPy开发及参考证据](v1-results/pft-optics-numpy-reference-a/manifest.json)
保留EHPC270的69项、271的103项实际0，二者均在设备验证前完成；272在PBS计算
节点生成47组量化32／64位输入参考及两种MOST整柱BGC参考。本机未跑参考物理。
274以独立连续三流ODE、矩阵指数和稠密联立边界求解对比全部47组；不复用生产
混合、薄层、倍增或逐层消元。雪地边界使用已有SNICAR反照率，不冒称其新的独立
参考。非近零量最大相对偏差：总冠层吸收0.0327302%、叶PAR0.0484668%、叶／枝
吸收0.0368761%；最大绝对差分别0.0400304 W/m²、0.223917 µmol/m²/s。
联合短波闭合仍要求2e-10 W/m²，近零用原绝对门。

冻结A版518文件的[EHPC273完整937CPU](v1-results/pft-optics-cpu-final-a/manifest.json)

均实际0。其中新组件4项覆盖47组32／64参考、全部624字段；CUDA32/JAX32最大
原始差2.00239802e-36，整数标志完全相等。旧雪辐射4项、相变11项也完成。
[A整柱BGC三项](v1-results/pft-optics-full-gpu3-a/manifest.json)随后实际0、2630.405秒，两步及MOST开关的全部返回字段最大差0；不能抵充最终D。

EHPC279另外发现合法完全不吸收的纯叶／纯枝／混合输入可能因面积加权舍入
使ρ+τ=1.0000000000000002，从而被严格被动性检查误拒；7例中3例复现，诊断
原样保留。B版只将内部ρ约束至≤1、τ约束至≤1−ρ，恢复解析凸组合的被动域，
没有四舍五入返回通量或放宽守恒门。三后端同步，新增三种组织边界CPU回归和
全部624字段的设备解析极限／同精度回归。[B全940CPU](v1-results/pft-optics-cpu-final-b/manifest.json)
已实际0、479.17秒。[B设备失败](v1-results/pft-optics-gpu20-failed-b/manifest.json)
保留：新增测试误要求枝干吸收逐位零，实际最大0.0002003 W/m²，在既定0.005硬界内；
叶光子分配仍精确为零。C只纠正该新增断言，保留全部624字段1e-6及原始输出，
随后真正同精度失败47/29328值、最大7.62939453e-5 W/m²。

定位为CUDA把完全散射极限更新放在吸收积分之后，JAX顺序相反，造成
`interception`与`1−(1−interception)`舍入不同。D统一CUDA与原JAX顺序，原精度/

[D整柱BGC3](v1-results/pft-optics-full-gpu3-d/manifest.json)随后实际父／worker0，
1547.608秒、0失败／跳过；32／64参考、MOST开／关及两次携带状态的原MHCN界满足，
