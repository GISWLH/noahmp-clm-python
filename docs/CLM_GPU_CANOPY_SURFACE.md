# 冬季冠层—雪—土壤表面时间步的原生后端

2026-10-14 开发记录。`gpu.canopy_surface` / `gpu.cuda.canopy_surface`
连接已验证的组件，实现与 NumPy `physics.canopy_column.surface_step` 对应的
非线性表面时间步。它包含真实的质量与焓状态更新，不再只是给定表温的边界。
降水截留、降雪输入、气候态沉降、重力排水和完整柱驱动连接是后续工作；
冠层冰雪和 MOST 通量反馈仍未实现，默认驱动未切换。

## 接口和求解顺序

固定十层叶片、最多五层雪和四层土。批量输入为：

- `c (N,5,9)`：雪质量、焓、厚度、粒径及五种杂质质量；
- `g (N,4,3)`：土壤总水质量、焓和厚度；
- `p (N,6)`：孔隙率、Campbell 指数、田间持水量、饱和导水率、石英比例、萎蔫含水量；
- `o (N,2)`：雪层数和未冻水选项；
- `a/u/f`：已有冠层叶面积、气象/交换参数及光合限制因子；
- `v (N,7)`：时间步、冠层液水质量、冠层焓、四层根系权重。

打包函数只编码状态和参数。运行时在设备上反演旧土壤相态，计算可用水、
根水比焓及 SNICAR/冠层辐射。每次试算都从同一旧状态出发：联立叶温与
空气温湿；移除实际蒸散水和携带的凝结相焓；将雪表层消失时原有短波吸收
转移至新的表层；求雪—土壤联合隐式热方程。带括区的割线求根让热方程表温
与冠层下边界一致，使用稳定的温差表达式，避免绝对 Kelvin 相消。

光学系数和供水在同一时间步内冻结。收敛后，使用真实非均匀雪/土温度梯度，
先压实再老化，最后排放融水并携焓入渗。输出保留排水前热状态、最终状态、
逐层热方程残差/数值精度界、水汽及径流携热、杂质出流和完整收支。
大气潜热与水相携带的焓分别入账，根到冠层的内部输送不重复算成柱外损失。

float64 表面残差容差为 2e-7 K；float32 使用两倍机器精度乘融点温度的
表示精度界，约 6.51e-5 K。另一终止条件是异号括区宽度小于上述表示精度界；
返回实际残差及两个端点，不把括区终止冒充残差终止。float64 的括区精度界
约 1.21e-13 K，独立于 2e-7 K 残差容差。叶能量迭代沿用原生边界的 float32 0.005 W/m²
逐层容差，float64 使用 NumPy 的 1e-7 W/m²。守恒检查以独立双精度汇总
重算整柱质量和焓，逐层热收敛界、实际叶残差和存储舍入界分别列账；
这些不是 10% 的物理误差豁免。温度比较只使用绝对 K 差。

## 开发时发现的问题

1. 初版 `a` 有 JAX 标量形状和 CUDA 无穷大常量的接口错误，未通过测试。
2. `b` 的混合相雪沉降工况中，NumPy 割线停在 `273.1499999999999 K`，
   实际热状态却严格位于融点。一次浮点间隔让霜/露分支不同：原生 float32
   与 NumPy 的 LE 差为 4.162588 W/m²，雪/土焓差分别达 271.442/487.913 J/m²。
   现在三个后端在精确雪相变平台重新求解，仅在完整耦合残差仍收敛时接收。
   同工况 LE 差降为 0.00398383 W/m²，雪/土焓差降至 1.54182/0.866458 J/m²。
   这是明确相变点的分支修正，没有扩大科学容差。
3. `b` 中融合 CUDA 的土壤转移调用在内联后出现异常局部质量，例如输入
   第二土层 90 kg/m²，得到约 1.3965e7 kg/m²。独立土壤组件没有该异常。
   `compute-sanitizer --tool memcheck` 对原失败复现报告 0 errors；它不能证明
   不存在其他编译或未定义行为问题。保留 `soil_transport_device` 的函数调用
   边界（`__noinline__`）后同样 16 工况均收敛。此处记录的是可复现的内联相关
   异常和局部规避，未声称已经证明具体 NVRTC 编译器根因。全字段同精度检查、
   独立质量/焓账及原土壤组件回归继续作为验证依据。
4. 扩大 `d` 到 50 工况时，float32 第 24 行（零基）表温残差
   7.808208e-5 K，经过 65 次试算仍未达到 6.51e-5 K 点残差条件；
   冠层最大逐层残差 0.002216265 W/m²，热方程各层已满足自己的数值界。
   JAX64 对同一批输入全部收敛。`e` 增加标准的有限精度括区终止条件，
   在输出中保留 `surface_root_bracket_k`，用原来的科学/守恒门重新检查。
   该失败行加入日常目标测试（扩至 25 工况），没有删掉失败或扩大 10% 门。
   修后该工况 12 次试算，括区为 `[273.66497802734375, 273.6650085449219] K`，
   宽度 3.051758e-5 K，恰为一个 float32 温度间隔；所选端点的实际残差为
   **−0.0001291633 K**，没有宣称其满足点残差门。完整状态和参考见
   `v1-results/p2-canopy-surface-e-bracket.json.gz`。
