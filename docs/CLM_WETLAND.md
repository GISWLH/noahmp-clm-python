# 简化湿地甲烷：三后端组件与NumPy整柱，设备整柱验证中

`physics.wetland`保留一个柱聚合CH4-C库，单位gC/m²。NumPy整柱已启用
`OptWetlandModel=1`；设备整柱正在验证，真实湿地观测验收未完成。

参考[CTSM甲烷说明](https://escomp.github.io/CTSM/release-clm5.0/tech_note/Methane/CLM50_Tech_Note_Methane.html)
2.25.1–2、2.25.5–7、2.25.13–14的过程与量纲：生产、氧化、扩散、冒泡和
显式碳储存。独立实现以下简化，没有复制CTSM代码。

- 输入是土壤分解器已经扣除的实际有机碳损失R。液水饱和度从0.8到1线性
  映射厌氧比例f；冻结时不生产甲烷。CH4生产为`R*f*r/(1+r)`，其余为CO₂。
  r默认0.2是CH4/CO₂比例；温度修正用甲烷Q10/供碳分解Q10的比，避免重复
  施加已有分解温度响应。默认甲烷/供碳Q10为2/1.5，参考温度295.15 K。
- 生产在一步内均匀发生，氧化和扩散线性竞争，使用精确指数积分。
  氧化常数默认1e-5 s⁻¹乘好氧比例与Q10，代替完整双Michaelis–Menten及O₂库。
  氧化转为CO₂；它不是从系统消失的碳。
- 水/气浓度按固定Henry系数0.035联系，总相容量为
  `L*(theta_liquid + theta_air/Henry)`，冰占孔隙。保存的是质量，水/冰体积
  变化不删除CH4。扩散距离L/2，水相D=2e-9 m²/s乘液水体积分数平方；气相
  D=2e-5 m²/s乘空气体积分数^(10/3)/孔隙度²。两条通路并联。
- 厌氧暖土在步末按15%环境压力、理想气体与Henry关系计算储量上限，超额
  冒泡释放。全冰封闭孔隙保留甲烷，融化可释放旧库。活跃厚度默认0.3 m。

以上阈值、厚度、扩散和简化氧化参数均可配置；它们不是已校准站点结果。
Henry和扩散系数保持常数，无完整温度依赖、分层O₂/CH4求解、植物通气组织、
横向淹水面积、压力扰动、雪阻力或溶解甲烷随排水输送。大气CH4边界取零，
因此不模拟大气甲烷吸收。整柱连接时必须明确这些限制，且从实际R分流，
不能同时把R全额计为CO₂。CH4质量输出按16/12转换，碳账仍统一为gC。

`methane_emission_gc_m2`另列CH₄，`total_atmospheric_carbon_gc_m2`为NEE加CH₄。
总碳库包含植物、土壤、作物种子和CH₄，收获产品与种子输入继续单列。
独立重算`ΔC + NEE_CO2 + CH4 + harvest - seed = 0`，不将分流碳再发一次CO₂。
水/焓均沿原有物理路径，湿地气体模块不直接改动水热储量。
