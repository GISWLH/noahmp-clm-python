# 实际冷季表面括区的浮点端点停滞

四站首个气候年冻结C/D在262个完整半小时后失败，实际失败区间为长岭
2007-01-06 11:00。原生MOST第12次试解只有长岭表面未收敛，另外三柱均收敛，
全部输出有限，冠层内部求解也收敛。[原失败、状态及设备追踪](v1-results/climate-surface-failure-262-a/manifest.json)
保留在库内，未放宽收敛或守恒标准。

## 原因与最小修订

实际有符号括区为`[264.868804932,264.868896484] K`，宽`9.1552734e-5 K`；
两端残差分别`+6.96182251e-5`和`−0.000359535217 K`。原5%区间内移量在此
量级不足一个Kelvin存储舍入位，割线试探值舍入回左端。仅加入device printf的
原算法重放显示，第52至59次仍逐值重复同一端点、括区和残差；60次迭代耗尽。
这属于数值迭代停滞，不是把5—10%物理精度门改成逐元素温差门。

NumPy、JAX和CUDA均仅增加同一保护：若试探值不严格在括区内部，改取
`left + 0.5*(right-left)`，再执行原完整物理试解和原验收。没有更改60次上限、
设备`2*eps32*273.15 K`的残差/有符号括区标准、NumPy温度门或MOST条件。
没有改土壤Thomas、状态单位或重复历史M1全量ΔT方案。

## 另一个仍未解决的海北薄雪事件

旧海北2002年度在6121个完整步之后、2002-05-08 12:30失败。EHPC PBS14用旧
源码及当前D对同一可信旧态分别重放，两份50次反馈轨迹相同；最终系数残差
`0.0340077444`，未满足原条件。MOST H在约`83.72 /195.59 W/m²`间交替。
旧态无雪、LAI=0，降水新增0.111 kg/m²雪；表面求解在完全蒸发和剩余约
0.0223 kg/m²、已全融的热单元之间切换，试解表温约`280.68 /277.12 K`。
剩余液水随后排走，所以最终无雪并不能证明步内热/水边界连续。

这与长岭float32端点停滞分别记录，当前端点保护不宣称修复该相变/拓扑事件。
EHPC对固定第49次交换边界的纯残差扫描找到连续根区间277.15—277.20 K及
280.65—280.70 K；277.95—278.00 K之间为雪完全蒸发的跳变，而非连续根。
原倍增括区可跳过靠近初始表温的连续根。[EHPC PBS17/18扫描与隔离实验](v1-results/ham-surface-branch-experiment-a/manifest.json)
先在雪水汽输送仍保留原表层的连续分支建立括区，再用原割线求解：独立Brent根
`277.165114643 K`，实验根`277.165114640 K`，相差3.19525e-9 K，H差
1.01774e-7 W/m²。完整旧态10次MOST接受，H/LE为83.358291 /128.569697 W/m²，
水/热/C/N残差2.34951e-14 kg/m² /−4.59841e-9 J/m² /−5.99285e-13 gC/m² /0 gN/m²，
分别满足原数值界。该实验尚不是生产改动，需补齐回归及JAX/CUDA同步。保留守恒、原50次MOST条件及
原参考配置，不通过增加迭代次数或选择较好观测通量来掩盖它。
第一次旧源码重放因独立源包少了SNICAR表在物理前失败；补齐与原源清单哈希
相同的两份表后完成上述两份重放，失败与补齐记录均保留。
