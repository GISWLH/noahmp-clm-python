# 有限冰川柱：质量、焓、融水与雪—冰导热

P5开发入口，尚未完成气象驱动完整柱及官方冰川输出验收。
`physics.glacier`提供NumPy参考，`gpu.glacier`及`gpu.cuda.glacier`提供设备计算。
没有将普通土壤的孔隙水当成永久冰盖，也没有隐含补充冰源。

依据[CLM5冰川技术说明](https://escomp.github.io/CTSM/release-clm5.0/tech_note/Glacier/CLM50_Tech_Note_Glacier.html)
区分积雪、冰层和融水出口；雪—冰界面使用
[共享有限体积热通量](https://escomp.github.io/CTSM/release-clm5.0/tech_note/Soil_Snow_Temperatures/CLM50_Tech_Note_Soil_Snow_Temperatures.html)。
只参考方程与模块职责，未复制CTSM源码。本实现是显式有限冰储量简化：
最多5层雪、4层纯冰，无CISM、海拔分级、冰流、无限替换冰库或冰盖动力学。
冰川耗尽后返回空冰状态；下一次热步要求外部明确处理耗尽，不自动创造质量。

冰焓以273.15 K纯冰为零，单位kg/m²、J/m²。冰密度917 kg/m³、比热2100 J/kg/K、
融化潜热334000 J/kg，默认导热率2.29 W/m/K、地热0.05 W/m²。
冰层质量变化相应改变厚度。雪与冰在同一个隐式焓方程中共享界面热通量，
固态、潜热平台、完全融化后的液水显热均保留。冰层产生的液水直接外排，
完整融化后的正焓随融水带出；不把暖水热量截断到熔点。

雪孔隙蓄泄沿用已验证的五层雪算子。底部雪融水接触剩余暴露冰层，先按实际
冷含量冻结，剩余液水外排；如果表层冰完全融化则暴露下一层。雪阻水溢流、
冰层融水及暴露冰上的剩余液水分别核算。五类黑碳/尘埃质量随融水守恒转移，
裸冰光学的杂质反馈尚未实现，裸冰反照率参数为固定值。

明确包含超过5 kg融冰潜热的余热。
