# CTSM 同条件边界只读复核（WP，2026-10-25）

结论：原 R/S 是有价值的固定 SP 工程参考，不能直接作为当前 JN／NM 动态 C/N 三站的同条件验收。旧 R 首日 H −33.1266%、GPP +192.851% 是旧 NumPy96 前 48 步的记录，不是 JN 的新结果，也不是生产参数需改的证据。本次只读取文档、源文本、原 JSON／namelist 并计算文件哈希；没有读取物理数组做计算、导入模型、提交任务、调参或改观测／QC。

原始对标和后续输入核对分别见 [冷初态匹配](CLM_CTSM_COLD_INITIALIZATION.md)、[生理输入](CLM_CTSM_PHYSIOLOGY_INPUTS.md)、[JN 水分与气孔修订](CLM_BALL_BERRY_STRESS.md)。

## 已闭合与不能重复归因的事项

- 固定 CTSM `fdfc03a0...`／CIME `d8e9b894...` 的 2930 源文件未改。R/PBS231 模型／PBS 0，17520 正区间；S/PBS238 模型／PBS 0，48 步及逐步 restart，27 个共享历史字段与 R 前 48 步完全相同。无需重跑 R/S48。
- R 全年实际陆面 TBOT、QBOT、WIND、PBOT、FSDS、FLDS、ZBOT、PCO2 和四短波分量符合原输入的历史 float32 表示。O 的 COPYALL 已消除早期 N 的 77 项 QBOT 截断差；R 的 QBOT 最大原值差 `9.3057880846e-10 kg/kg`。共用 Erbs、VIS/NIR 各 0.5 和全部原时间区间；原构建参数 CO2=367 不可代替实际 PCO2 读回。后写的冠层文档中“实际 CO2 待核对”不能抹去这项已完成的输入审计。
- R 积分前指定 T=278.722 K、液水 θ=.28、零雪／截留／地表水和七冠层几何字段的读回误差均 0；首区间零 LAI/SAI 已消除。只匹配这些指定量，不等于全库存、深度或全部内部记忆相同。
- 开发柱土壤胁迫选项 2/3 已改用真实饱和吸力与 Campbell 势；234 个独立点最大绝对差 CLM `6.66134e-16`、SSiB `1.55431e-15`。这是 Noah-MP 的 CLM/SSiB beta 公式，不是 CTSM 植物水力学，也未改 Qia 的选项 1。
- JN 所继承 IV 生产修订已经将水因子与氮因子分开：beta 只作用 Vcmax、Rd、最小气孔导度（下限 1e-6 mol/m²/s）；不再额外缩放 BB 斜率、Jmax、TPU。540 例原独立耦合参考已完成，NumPy Ci 最大差 `5.68434e-13 ppm`、gs `3.88578e-16 mol/m²/s`；专项 GPU37 实际父 0。无需重复这套验证。原 R BTRAN 全 48 个有效值约 `.9999024868`，原 NumPy 初态约 1；这不能支持把旧首日约三倍 GPP 归因于水分胁迫。
- SAI、叶／枝光学、NOAA 日长容量、十日温度记忆及垂直叶氮均已有显式接口；旧文档“未实现”的段落是历史状态。接口存在不等于每个站点配置启用。当前 JN 三站气候试验与旧 Qia capacity／optics 分支必须分开标识。
