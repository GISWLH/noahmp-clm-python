# 植物碳氮组件（整柱连接继续开发）

叶、聚合茎、细根分别保留C/N，加非结构性C/N储备，单位gC/gN每平方米
地表。先支付维持呼吸，再将可用碳用于新生长；叶暗呼吸来自冠层光合求解，
只计一次。原生分为凋落、需求规划、实际氮分配三步，土壤模块在中间执行
植物吸收与微生物固持竞争，不能凭目标C:N创造氮。

依据[CLM5分配说明](https://escomp.github.io/CTSM/release-clm5.0/tech_note/CN_Allocation/CLM50_Tech_Note_CN_Allocation.html)
理解组织和储备结构，独立实现简化分配。默认叶/茎/根比例0.3/0.4/0.3为
显式可修改配置，不声称是所有PFT通用参数。叶/根目标C:N为25/42；聚合茎
按10%活木C:N=50、90%死木C:N=500求有效C:N=263.158。叶、茎、根寿命
365、10950、365天；新碳10%存储、已有储备30天指数释放，SLA=0.02 m²/gC。
LAI由真实叶碳×SLA/植被覆盖度得到；季节控制只给生长上限和叶保留比例。

[CLM5呼吸章节](https://escomp.github.io/CTSM/release-clm5.0/tech_note/Plant_Respiration/CLM50_Tech_Note_Plant_Respiration.html)
规定新生长呼吸系数0.11；分配章节残留的旧0.3不采用。
根/活茎维持呼吸按组织N及温度Q10计算，参考20°C；
[官方CNMResp结构](https://raw.githubusercontent.com/ESCOMP/CTSM/release-clm5.0/src/biogeochem/CNMRespMod.F90)
给出的基础系数2.525e-6 gC/(gN·s)、调谐Q10=1.5作为默认参数。
没有复制Fortran代码。聚合茎中参与维持的N比例为0.526316。

凋落采用指数存活率；叶/细根进入代谢、纤维素、木质素三类凋落物，默认
比例0.3/0.45/0.25；茎进入粗木库。按[FUN免费氮回收关系](https://escomp.github.io/CTSM/release-clm5.0/tech_note/FUN/CLM50_Tech_Note_FUN.html)
回收落叶N超过落叶C/(1.5×目标叶C:N)的部分，进入植物N储备。
生长前优先修复既有组织N缺额；新生长允许C:N升至目标的2倍，继续缺N则
限制生长，未用碳留在储备。叶N/C相对目标的比例反馈Vcmax/Jmax/TPU。
NEE向大气为正：RA+RH−GPP；土壤呼吸为根呼吸+RH。

本实现没有完整FUN的有偿获取、固氮、同位素、完整PFT木本异速生长或
CLM独立活/死粗根库；死亡只是显式背景及季节凋落，未做饥饿致死模型。
与CLM允许负储备不同，这里限制实际呼吸到可用碳并报告未满足需求。
饥饿时冠层潜在叶暗呼吸与实际C支付可不同，这个简化需在完整柱接入后
明确评价。独立组件的指定GPP不是观测驱动的生长验证；真实整柱GPP/NEE、
长期spinup与FLUXNET验收仍待完成。

NumPy先完成独立存活率/Decimal现金与氮收支、缺氮反馈、休眠、饥饿和
两年植物—土壤联算。全年组织C与指数解析解最大相对差1.15887e-15，
