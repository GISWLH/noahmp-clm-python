# 整柱生物地球化学连接（NumPy完成，原生整柱待同步）

`CLMColumnState.with_biogeochemistry(BGCState, BGCParameters)`连接显式植物与
土壤C/N库，要求分层冠层。LAI成为叶碳×SLA/植被覆盖度的只读派生量；
选项5的GDD控制目标LAI和季节落叶比例，不能直接产生生物量。无季节控制
时采用参数中的最大LAI。新增状态不进入v0.2旧ABI，旧设备打包入口明确
拒绝BGC，避免静默丢失C/N。原生植物/分解组件已完成，整柱设备调度待做。

每步先用第三土层旧温度更新GDD，计算叶保留比例并将背景/季节凋落实际
C/N送到凋落物。用剩余叶碳的实际LAI及叶N因子求完整冠层—雪—土壤水热；
叶面积下降造成的冠层水量超容量及携热由原有截留模块路由，不能删除。
随后以实际冠层GPP和叶暗呼吸规划植物需求；土壤分解与植物竞争矿质N，
按实际授予的N生长、修复组织或保留储备。新生物量作用于下一步物理，
是显式算子分裂；诊断分别输出lai_before、lai_used、lai_after及target_lai。

分解是柱聚合库，使用物理步后的第一土层温度和液态水饱和度；Campbell
基质势默认饱和值−0.0001 MPa，与本仓库已有胁迫参数化一致，可显式修改。
根呼吸使用根分布加权Q10，再映射成等效温度，不能先平均温度再算Q10。
氮沉降为每步gN/m²，氧因子为显式0–1输入。氮因子由真实叶C/N决定，
不能再传入外部倍率绕开反馈。非BGC柱拒绝非默认氮/氧参数。

碳账：新总C−旧总C+NEE=0，其中NEE=实际RA+RH−GPP，向大气为正。
氮账：新总N−旧总N−沉降=0；植物吸收、凋落及矿化都是内部转移。
每步数值界为128×float64 epsilon×相关存储和外部收支绝对尺度。
水/焓账沿用实际物理出口并独立复核，不用10%代替守恒。
