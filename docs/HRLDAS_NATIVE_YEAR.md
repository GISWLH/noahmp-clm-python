# 原生柱完整年/月评价入口

`benchmarks/compare_hrldas_native_year.py`用于完整本地标准时日历年的数值评价。
当前真实I年度仍未完成；本页记录入口验证，不报告虚构的完整年结果。
现有[首周科学差异](HRLDAS_SUCTION_PREFIX.md)及未通过结论保持。

入口要求原生报告为`complete`、原请求步数全部完成、源码未变；全年精确覆盖
1月1日至下一年1月1日，365/366天、12个完整月。原官方UTC时间显式转换为
配置中的固定本地标准时，逐间隔严格对齐，缺步、重叠、偏移或部分年份均拒绝。
CLI仅在EHPC PBS计算节点执行。

官方协议、生成器、完整归档及其中prepared/audit原字节保持身份，原强迫文件
逐个核对SHA256。可直接配对原配置，或使用仅限既定显式吸力头变化的派生绑定；
后者复用首周的严格配置检查，不容许更换叶参数、测高或初水。没有改写旧清单。

日/月ET、径流按间隔量相加（mm），H/LE按功率乘间隔秒数积分（J/m²）；
均值偏差仍采用[V1固定科学容差](V1_ACCEPTANCE.md)。土温先转摄氏度，
状态取等间隔的区间末均值。近零量用绝对门，常量通量的相关系数未定义时标
“未测”。旧通用评分入口遇到不完整月也标“未测”，不会作为月验收通过。

守恒独立于10%科学精度门：逐步及累计水/热/C/N残差逐列检查原数值界；
跨气候段必须提供报告中SHA链接的前段检查点，原累计数值界不清零。
最终检查点按原SHA和代次绑定，16份状态数组齐全且有限，从雪、土壤、逐层
冠层、植物和土壤C/N原数组重新求广延存量，核对初始存量及累计边界净输入。
此核对不重新推导每步边界输入或杂质通量；逐步独立预算由原运行器另行记录。
