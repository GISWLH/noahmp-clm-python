# 四站沉降强迫与时间映射

2026-10-17准备固定2000年气候态，供后续连续试验使用。四站坐标来自已核验
的各自强迫清单，海北采用JPF产品坐标37.607432°N、101.332°E；没有混用
FLUXNET2015旧坐标。完整四节点值、双线性权重、月序列、单位、哈希及可重复
提取脚本见[输入证据](v1-results/deposition-inputs-a/manifest.json)。

气溶胶采用[NCAR月气候态文件](https://svn-ccsm-inputdata.cgd.ucar.edu/trunk/inputdata/atm/cam/chem/trop_mozart_aero/aero/aerosoldep_monthly_2000_mean_1.9x2.5_c090421.nc)，
SHA256 `2e920f2558685c790e904185bd3a9150435f31e3dca2d2ebb1aa1f6b60ae61ff`。
BC为BCDEPWET+BCPHIDRY+BCPHODRY；四粒级尘埃分别汇总WD/DD，单位均为kg/m²/s。
疏水/亲水BC进入当前单一BC示踪量；OC没有进入五示踪雪模型，不能把它并入BC。
文件名和date变量标2000，但global case/history含1850标签。另取1850文件后
实际比较所查BC/尘埃数组不同，保留这项元数据不一致，不能宣称已彻底消除。

氮采用[NCAR历史年度沉降](https://svn-ccsm-inputdata.cgd.ucar.edu/trunk/inputdata/lnd/clm2/ndepdata/fndep_clm_hist_simyr1849-2006_1.9x2.5_c100428.nc)

## 运行器约定

两个FLUXNET运行器共同使用`benchmarks/fluxnet_deposition.py`：配置必须二选一
`aerosol_deposition_kg_m2_s`（长度5常量）或
`aerosol_deposition_monthly_kg_m2_s`（12×5月中心通量）。缺失、同时提供、负值、
非有限值或形状错误均在运行前拒绝。月序列按实际公历月长周期线性插值，取
每个强迫间隔的中点；不同柱使用各自日期，年界连续。月中心通量不是月累计量。

`nitrogen_deposition_gn_m2_s`仍是显式常量，源年值除以365×86400得到速率；
公历闰年的输入自然是该年值的366/365倍，未静默改单位。源数据和月映射均写入
实际配置并随配置哈希固定；运行器源哈希包含新映射模块，旧检查点不能混入
另一版本的运行器。CUDA/JAX仍使用本次量化后的实际沉降进行五示踪及N独立记账。

本地映射、续跑、原始强迫回归50项1.24秒，冻结`p6-deposition-runner-b`的Linux
同组50项2.20秒；其中分段连续性用人造守恒倾向测试，不代替设备物理核验。
B的420文件清单SHA256为
`f0c071e3e67b291b59c33b4eb050560a40a4c91a994085c1fbd799b7f8711c97`。
初次A打包遗漏既有非Python夹具，执行前发现并补齐为B；A未用于测试结论。
四站同一初态、仅改变沉降的[首日NumPy/CUDA核验](v1-results/deposition-runner-b/manifest.json)
已全部完成，共384柱步。CUDA四柱48步耗时96.081秒；NumPy各站耗时
380.414 /403.974 /500.487 /70.300秒（长岭/千烟洲/长白山/海北），共享主机
且运行方式不同，这些耗时不用于性能加速比。CUDA各柱逐步及累计M/H/C/N、
五类杂质按实际量化输入独立审核；最大累计M/H/C/N绝对残差为
`1.41563476e-4 kg/m² /169.438059 J/m² /0.00707504945 gC/m² /
0.000941716717 gN/m²`，均在原逐柱数值界内。没有用10%门豁免守恒。

全部变量的后端日偏差满足10%或预设近零绝对容差；可定义的H/LE/GPP/NEE
相关最低`r=0.999999997981`。日ET/H/LE/GPP/NEE最大非近零相对偏差分别为
`0.00094862% /0.00176969% /0.00094428% /0.00024411% /0.00020517%`。
最大瞬时H/LE差`0.00626693 /0.00438623 W/m²`，土温差`0.000136346 K`，
体积含水量差`1.02313e-7 m³/m³`。海北本日GPP双方均为0，相关无定义，仍按
绝对门评价；近零H/NEE也没有使用相对偏差。四站原始轨迹和恒定序列的null
相关均保留，不能把此后端对照称为FLUXNET观测验收。

随后首个全年初始化试验在千烟洲第一步暴露出原干叶新凝结的相变缺口；
其失败状态与本次已完成的旧初态首日分开记录，年度续跑停止等待修复。

当前简化BGC没有淋失/反硝化，正沉降使系统总氮持续积累。不能据短期C/N守恒
声称达到总氮平衡；真实气候spinup需报告该边界及实际碳库漂移。此年度N输入
也不能称作[CLM5月沉降及完整外部氮循环](https://escomp.github.io/CTSM/release-clm5.0/tech_note/External_Nitrogen_Cycle/CLM50_Tech_Note_External_Nitrogen_Cycle.html)。
