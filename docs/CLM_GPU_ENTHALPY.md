# 雪—土壤联合热量的原生 GPU 实现

2026-10-14 开发检查点。新增 `gpu.enthalpy` / `gpu.cuda.enthalpy` 和
`gpu.column_heat` / `gpu.cuda.column_heat`，分别计算土壤相态—焓反演，以及
最多五层雪、四层土壤的共享隐式热方程。它们在设备上计算相态、导热率、
Newton 方向和相变事件；host 只打包和检查输入，不代算物理结果。
NumPy 方程及此前独立 SciPy 核查见[联合焓报告](CLM_COLUMN_ENTHALPY.md)。

这一步完成的是热状态和联合传热组件。完整新柱的雪水文、SNICAR、冠层
储热和冬季交换仍须同步到设备，尚无新冬季整柱 GPU 或外部站点验收结论。

## 状态、守恒与精度

土壤焓以冰点干土/冰为零点，液水包含熔化潜热。沿用已平滑的未冻水
选项 1/2 和解析热容；反演范围 150–400 K，超域明确报错，不裁掉能量。
焓为守恒状态，反演得到的重建焓仅作诊断，不能覆盖输入焓。
计算温度偏移量 `T-273.15` 保留冰点附近的信息，输出仍给出物理 Kelvin。
旧版土壤 AHC/Thomas 完全未改，没有重新尝试 M1 全量 ΔT 方案。

联合热方程是固定旧态导热率的后向 Euler；雪使用密度型导热率，土壤
使用已有 Johansen 近似。土壤底部绝热，顶部可给定热通量并联立线性
空气换热。每个内部界面只计算一次通量，以相反符号进入相邻储库。
雪完全融尽后仍保留其液水焓，由后续水文步骤搬运，不丢弃余热。

float32 守恒检查独立于 10% 科学偏差口径：逐层残差必须小于其算术
分辨率界。该界包含该层焓/外部输入的浮点舍入，以及相邻层温度舍入
经界面导度和时间步传播的误差。土壤温度误差使用实际反演残差/热容，
不让深层大储量为表层小储量统一设置宽松容差。专门验证冰点雪面仅
输入 1 J/m² 时，该热量进入雪焓，绝不能被深层约 1e8 J/m² 储量掩盖。
总收支另由 host float64 对实际设备输出重算，不做事后能量补偿。

输入从 float64 量化到 float32 时，饱和质量、厚度和孔隙度独立舍入
可能使质量略超舍入后的孔隙上限。打包器只将这种边界质量向内舍入，
保留焓输入；此操作发生在输入量化阶段，不是时间步中的水量修正。
对照使用完全相同的量化输入。质量近零绝对容差 1e-4 kg/m²，等价于
0.1 微米水当量；温度只报告 K 的绝对差，不除以绝对 Kelvin。
CUDA32/JAX32 同精度门保持 `rtol=atol=1e-6`。

## 相变事件的诊断与修复

保存的失败输入位于 `tests/fixtures/heat_merit_phase_events.json`。

更早的 51 柱测试有两个 float32 失败：一个相变平台层受到相邻暖雪
温度舍入的影响，残差 0.265625 J/m² 高于只计本层的 0.1501604 J/m²
精度界；另一个量化后的饱和质量超出量化孔隙，连 NumPy 同输入也会
拒绝。分别补齐相邻温度舍入的传播项和输入边界定向舍入，保存
[原始测试](v1-results/p2-enthalpy-earlier-d-targeted.log.gz)及
[逐柱诊断](v1-results/p2-enthalpy-earlier-d-probe.log.gz)。

1. 初版扩大样本中，7 个双精度薄雪柱在相变端点停止，NumPy 在
   6–10 次迭代内收敛。原因是线搜索按每个候选自身的舍入界归一化，
   该界在相变平台端点跳变。修复为在一次 Newton 方向的线搜索内
   固定权重；最终收敛仍逐层使用真实精度界。
2. 随后一个 float32 柱在相变事件的小步长下，表层焓变化低于一个
   ULP，最大归一化残差保持 2474271，其他层却在下降。线搜索改用
   顺序累加的加权 L1 残差判断进展；逐层最大残差仍是停止条件。
3. 连续推进第 94 步发现，某雪层距完全融尽仅一个 float32 ULP，
   初版将“距端点四个 ULP 内”视作已到端点，跳过实际相变事件。
   相邻层残差 0.0625 J/m² 超过其 0.05503 J/m² 精度界。现在只把
   精确到达的端点当作相变端点，事件步会明确落在该值上；未增加容差。

## 未覆盖范围

连续热试验固定质量与几何，不包含降雪、融水排出、压实、杂质、光学、
根吸水或冠层耦合，不能充当完整冬季柱或 365 天水热试验。原先的
365 天 NumPy 雪—土壤组件证据仍单独保留。新组件目前固定四土层，
变层数土壤尚未支持；原有无雪 GPU 柱入口也尚未切换到新焓状态。
CLM5/HRLDAS 官方输出和 FLUXNET/积雪观测验证均未由本组件检查替代。
