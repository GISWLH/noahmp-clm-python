# 分层冠层冰水—叶温—空气联立原生后端（开发中）

`gpu.canopy_phase_energy` 与 `gpu.cuda.canopy_phase_energy` 在设备上完成十层
冠层质量/焓相变、叶温、Farquhar/Ball–Berry、冠层空气温湿与共享根水联立。
原生SNICAR/冠层短波、长波、气体交换、根水分配均在设备运行；包装函数只
传递输入与数据表，没有主机NumPy物理替代。物理定义和独立方程参考见
[NumPy相变联立](CLM_CANOPY_PHASE_ENERGY.md)。这仍是固定地面边界组件，
**分层冠层冰水尚未接入完整柱，默认驱动未切换，真实科学验收未完成**。

两后端使用同一十二未知量Newton系统、数值Jacobian、带主元的消元和残差
回溯；NumPy独立实现用最小二乘解线性系统。保留完整融化平台，不以AHC平滑
替代相变；空水层冗余相变坐标按已验证的物理残差移到平台端点。
float64/float32单层能量求解容差分别5e-5 / 0.005 W/m²；这些是明确的
数值残差界，守恒核算另以实际M/H、根水和水汽携焓重新计算。

## 保留的失败与定位

`b`的15个工况均收敛，但冷冰/冻结同精度未通过，最大叶温差3.05176e-5 K。
相同试探状态的298项输出完全相同；冷态初值独立探针发现XLA合并Ci/Cw
乘除后改变了一个float32间隔。分别保留乘法和除法的舍入后，`c`的目标
4项完成，15工况同精度最大差0。

`d`扩大75工况全部满足物理偏差门，但6个随机工况仍未满足同精度门。
逐迭代追踪确认，初值、残差、Jacobian、线性解及缩放均一致，首个差异
来自回溯试探坐标。独立探针显示JAX `exp2(-3)`为0.1249999925494194，
CUDA为精确0.125；k=5/13/15/17也有差异。`e`将18个半步写成精确的
二进制数，CUDA使用`ldexpf`；75工况全部字段随后一致。六个输入保存在
`tests/fixtures/canopy_phase_native_regressions.json`，不是删掉失败样本。
