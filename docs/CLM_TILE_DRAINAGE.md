# 简化瓦片排水开发记录

依据[Noah-MP官方技术说明](https://www2.mmm.ucar.edu/wrf/users/physics/phys_refs/LAND_SURFACE/noah_mp_tech_note.pdf)
3.7节式302—304的田间持水量超额排水结构，独立实现简化组件。
原文式303的排版缺括号且单位不一致，304未完整列出超过流量上限的分支；
这里明确采用量纲一致的“超额液水与时间步排水能力取小者”。
不声称复现原Fortran逐点输出；官方HRLDAS和站点排水对照仍未测。

默认管深1 m、田间持水量0.28 m³/m³、最大排水10 mm/day均是可配置假设。
只排管深所在的一层，恰在层界时选择较浅层；不支持超出土柱的管深。
液水保留量为`max(1000*field_capacity*dz - ice_mass,0)`，超额不超过实际液水；
一步外排不超过`maximum_mm_day*dt/86400` kg/m²。
冻管层（低于融点或含超过1e-9 kg/m²冰）关闭，避免引入未经校准的冻层排水率。
这是选项1的简化方案；多排水层、Hooghoudt选项2、反向灌排与硝酸盐淋失未实现。

排水携带实际层温的液水比焓`Lf+Cw*(T-Tf)`；从真实土壤水量和焓同时扣除，
不凭空恢复地温或截断能量。独立水/焓账按浮点舍入界核算。
完整柱选项、径流诊断及BGC湿度反馈已接入NumPy；设备整柱验证中。
